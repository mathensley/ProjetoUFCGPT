# UFCGPT

## Projeto de Agente Inteligente para Respostas Relacionadas à UFCG

Este projeto tem como objetivo criar um agente inteligente capaz de responder perguntas relacionadas à Universidade Federal de Campina Grande (UFCG), usando dados reais para fornecer respostas precisas e contextualizadas. O sistema será implementado através de um conjunto de agentes especializados, cada um responsável por uma área específica da universidade.

### Ideias para Implementação
#### 1. Agente para Informações Gerais da UFCG

Este agente será responsável por responder a perguntas sobre a UFCG, mais especificamente no que se refere ao campus de Campina Grande. Entre os tópicos abordados estão:
- Estágio
- Matrículas
- Disciplinas
- Professores
- Plano de aulas
- Ementa
- Calendários
- Cursos
- Campus
- Centros
- Unidagit pudes
- Turmas
- Estudantes
- Regulamento
- Guia de Matrículas
- Biblioteca
- Prédios 

O agente deverá ser capaz de fornecer informações precisas e atualizadas sobre esses temas, ajudando alunos e professores no dia a dia.

### 2. Agentes para a Biblioteca da UFCG
Neste módulo, criaremos um grupo de agentes especializados em ajudar alunos e professores a encontrarem livros relacionados a determinado assunto. A ideia é usar Processamento de Linguagem Natural (PLN) para implementar métodos que relacionem os livros disponíveis nas bibliotecas da UFCG com tópicos ou disciplinas de interesse.

### 3. Agentes para as Últimas Notícias da UFCG
Este conjunto de agentes será responsável por buscar e fornecer as últimas informações sobre a UFCG, como editais, eventos e notícias gerais. O agente irá consultar fontes oficiais e fornecer ao usuário as informações mais recentes sobre a universidade.

### 4. Agentes para o Regulamento da UFCG
Esses agentes terão como foco as questões regulatórias da UFCG, com ênfase no regulamento acadêmico para o período 2024.1. Eles serão capazes de responder a perguntas sobre as normas da universidade, como critérios de avaliação, regras de matrícula e outros aspectos do regulamento acadêmico. O objetivo é tornar mais fácil para os estudantes e professores entenderem os detalhes do regulamento.

### 5. Agentes para o Guia de Matrículas
O último conjunto de agentes será voltado para o Guia de Matrículas de Dalton. Esses agentes ajudarão os alunos a entenderem o processo de matrícula, respondendo a perguntas relacionadas a prazos, procedimentos e requisitos para efetuar a matrícula nas disciplinas do período. Eles serão baseados no conteúdo do guia e fornecerão respostas detalhadas sobre o processo.

## Funcionalidades do Projeto
- Respostas contextuais e precisas: Cada agente fornecerá respostas detalhadas sobre sua área específica de atuação, usando dados reais da UFCG.
- Processamento de Linguagem Natural: Utilização de técnicas de PLN para melhorar a compreensão de perguntas e a precisão das respostas.
- Integração de múltiplos agentes: Cada grupo de agentes (informações gerais, biblioteca, notícias, regulamento, guia de matrícula) trabalhará de forma independente, mas também será capaz de colaborar entre si quando necessário.

## Tecnologias Utilizadas
- Python: Linguagem principal para desenvolvimento de agentes e processamento de linguagem natural.
- NLTK e SpaCy: Bibliotecas para PLN, usadas para processar e entender as perguntas dos usuários.
- Flask: Frameworks para construir APIs que servirão os agentes de resposta.
- Eureca: Dados abertos da Universidade Federal de Campina Grande.
- LangChain.
- LangGraph.
- BERT.
- vector DB.
